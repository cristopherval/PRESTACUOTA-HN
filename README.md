# PrestaCuota HN — Landing Page

Landing page de venta de **PrestaCuota HN**, la aplicación web para prestamistas que
permite administrar clientes, préstamos, cuotas, pagos y cobros desde el celular.

## 🚀 Sitio en vivo

La app: **https://prestacuota.fitcore-hn.com**

## 🛠️ Tecnología

- HTML5
- Tailwind CSS (vía CDN)
- CSS propio para mockups y animaciones (`css/styles.css`)
- JavaScript vanilla para menú, acordeón FAQ y animaciones de entrada (`js/main.js`)

Sitio 100% estático — no requiere build ni servidor.

## 📁 Estructura

```
.
├── index.html        # Página completa
├── css/styles.css    # Mockups y animaciones
└── js/main.js        # Interacciones
```

## 💻 Ver en local

Abrí `index.html` en cualquier navegador, o serví la carpeta con un servidor estático:

```bash
python -m http.server 8000
# luego abrí http://localhost:8000
```
